# Oriana.terminal

This is an old project, i am going to make it public as soon i can get it organized.

All the code, source, maybe even the models i used to make it work.

## Quick summary.
Totally open and customizable AI terminal chat, keeping all instances local, displaying a cute chat with themes in an electron window.
Works with OpenAI, Anthropic, Google Gemini, and local models.

Here is the original repo, that doesn't have the code: https://github.com/PuplProject/OrianaTerminal (totally abandoned)
